# Homepage hero: new portrait + "Wordmark Orbit" redesign (26 Nov 2026)

## What the owner asked

1. **Brief "Landing Page Hero Image Update"** (PDF, 26 Nov 2026): replace the doctor image in the homepage hero with the new
   portrait; keep the layout; display properly on desktop and mobile; use the supplied PNG without changing the facial features,
   natural hair or the OET branding on the blue scrubs.
2. After a pixel-exact preview of the plain swap, the owner asked to **revamp the hero** ("too much empty space", "more modern,
   wow effect") and to see **four variations** as artifacts. Previews: A Spotlight Panel, B Midnight Aurora, C Bento Grid,
   D Wordmark Orbit. **The owner chose D.**

## What changed

- **Portrait**: the PDF embeds the portrait as a lossless 1122x1402 RGB image with a soft mask (alpha); it was extracted with its
  transparency and only resized (Lanczos) to `assets/img/hero/dr-hesham-2026-{480,720,960,1122}.{avif,webp}` (AVIF q60, WebP q82,
  alpha kept). The eight old `dr-hesham-<w>` files are deleted (still in git history). New file names on purpose: `.htaccess`
  serves images `max-age=31536000, immutable`, so the old names would have kept the old photo on returning visitors' screens.
- **Structured data**: `person.json` `image` and the 17 page partials that repeat the Person node now point at
  `dr-hesham-2026-960.webp`, so search engines show the same portrait as the site.
- **Hero** (`site/src/partials/index/main.html`, `assets/css/oet-hero.css`, homepage only): option D, ported from the approved
  preview with the class names moved into the existing `oet-hero__*` namespace. All content and links kept: H1 (text unchanged),
  lead, Join Free Community (popup), See pricing & packages, WhatsApp / Telegram / Facebook, 7+ / 20K+ / 500+ with their source
  links, 5.0 Google rating, 7,000+ community, the Free General English Placement Test card and its tracked link.
- **Preload** (`site/src/partials/index/meta.html`): AVIF `imagesrcset` + `imagesizes` identical to the `<picture>` source, with
  `sizes` set to the measured rendered widths (one download per visit; checked).
- **Checks** (`site/scripts/verify.mjs`, block "Homepage hero"): new files present, old files and references gone, preload ==
  source, every hero text and link present, decoration `aria-hidden`, transform-only headline entrance, animations inside
  `prefers-reduced-motion: no-preference`.

## Verification (26 Nov 2026, local build)

- `npm run build`, `node scripts/verify.mjs`, `node scripts/postbuild.mjs --check-root`, `node scripts/qa-redesign.mjs --no-shots`:
  all pass.
- **Built page vs approved preview**: pixel-identical (0.000% of pixels differ) at 1920, 1440, 1366, 1024, 820 and 390 px;
  0.056% at 360 px (the photo now loads one size sharper there).
- **Cards vs face, hair and OET logo**: measured against the cutout's own alpha at 21 widths (320 to 2560 px): no card or chip
  covers them; no horizontal overflow at any width.
- **Behaviour** (animations on): Join Free Community opens the community popup; counters land on 7 / 20 / 500; no console errors
  at 1440 and 390 px; `html.oet-lite-motion` stops the orbit and chips on phones.
- **Performance** (`node scripts/perf-lab.mjs --base http://localhost:8000`, throttled mobile, 3 runs, same machine):


  | Homepage `/` (median of 3) | LCP | FCP | CLS | TBT | Transfer |
  |---|---|---|---|---|---|
  | Before (old hero) | 5,960 ms (H1) | 5,960 ms | 0.000 | 223 ms | 1,028 KB |
  | First build of D | 6,728 ms (OET wordmark) | 6,196 ms | 0.000 | 235 ms | 1,050 KB |
  | Shipped (wordmark entrance transform-only, phone `sizes` 360 px) | 6,128 ms (OET wordmark) | 6,128 ms | 0.000 | 242 ms | 1,038 KB |

  The first build let the giant OET wordmark (now the largest element on a phone) fade in, which pushed LCP about 0.6 s past
  first paint; the shipped build paints it at once, so LCP equals FCP again. The remaining ~0.17 s and +10 KB come from the
  larger portrait on phones (it is shown much bigger than the old one); field data in Search Console stays the real judge.
