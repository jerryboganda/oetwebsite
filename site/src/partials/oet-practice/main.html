OET practice FAQ

Short answers before you choose where to practise.

Is any OET practice free?

Yes. The sample tests guide, model letters, role-play cards, score calculator and placement test are free. A free learner account also includes free Writing and Speaking sample results.

Can I practise OET on a computer?

Yes. Mock exams in the learner app can be set to computer, paper or OET@Home mode so you practise in the format you will sit.

Do I need an account to practise?

The website guides need no account. Timed practice, mocks and feedback run inside the learner app, which needs a free account.

Which skill should I practise first?

Start with the sub-test furthest from your target grade. The placement test and a first mock show where that gap is.
